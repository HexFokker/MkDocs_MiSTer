    PSX

    Sony PlayStation（PSX）の MiSTer コアは、これまでで最も機能が充実し、開発も活発なコアです：

    • 豊富なコントローラーオプション
    • BIOS リージョンの自動切り替え
    • 手動ファイル読み込みに対応したメモリーカード2スロット
    • 高速化モード
    • ゲーム内テクスチャ変更

    PSX の FPGA 実装を書くのは大変な作業で、Robert Peip（FPGAzumSpass）氏によるこのコアは現在も活発に開発中です。このページではその機能の一部を紹介します。

    コントローラー対応

    MiSTer PSX コアは、実機で利用できた非常に多くの操作機器に対応しています。

    • DualShock（アナログスティックと振動機能付きの後期コントローラー）
    • Digital Pad（アナログスティックなしの初期 PSX コントローラー）
    • Analog Pad モード（デュアルアナログスティックモード有効）
    • GunCon
    • NeGcon（OSD の "Wheel-NegCon" オプションでステアリングホイールとしても使える）
    • レーシングホイール（OSD で "Wheel-Analog" に切り替えると一部のアナログレーシングホイールが動作）
    • Mouse
    • Justifier
    • SNAC（実機 PSX コントローラー周辺機器を使うには専用アダプターが必要。このモードではメモリーカードや PocketStation さえ技術的に使える）
    • Analog Joystick
    • Pop'n Music Controller

    DualShock 対応

    DualShock コントローラーモードは万能の解決策です。理想的にはゲームが要求するものを判別し、そのゲームに適したモード（Digital または Analog）に自動で切り替わるはずです。ただし、コントローラーが誤ったモードのとき入力を受け付けないゲームもあります。この場合は手動で別のモードに切り替えて、問題が消えるか確認してください。

    実機 DualShock と同様、ボタン操作（コントローラーによっては複数ボタン）でデジタル／アナログモードを切り替えられます：

    • DualShock 4 または DualSense（PS5）コントローラーでは、中央のタッチパッドを1回押します。押すたびに Analog と Digital が切り替わります。
    • その他のコントローラーでは、OSD の "DS mode" 設定に応じて L3+R3+上/下 または L1+L2+R1+R2+上/下 を押します。

    メモリーカードの手動読み込み

    PlayStation のメモリーカードファイル（.mcd または .sav）は OSD で手動読み込みできます。デフォルトではスロット1に空のメモリーカードファイルが自動で入るため、ファイルはスロット2に読み込むのがおそらく最適です。あるいは OSD の Automount Memory Card 1 オプションをオフにして、スロット1の自動充填を止められます。メモリーカードスロット付きの SNAC アダプターが繋がっていれば、SNAC 経由で実機 PlayStation メモリーカードも使えます。

    Libcrypt 対応

    一部のゲームは "Libcrypt" と呼ばれるコピープロテクトを使い、これを回避しないと動きません。回避するには、ゲームの .cue ファイルと同じ名前の .sbi ファイルを隣に置きます。CD イメージがマウントされると自動で読み込まれます。.sbi ファイルの全コレクションは redump.info からダウンロードできます。

    音声・映像オプション

    Fixed blanks

    実機 PlayStation は開発者に多様な解像度を提供しており、画面外に画像を動かして画面を揺らすゲームもありました。どちらも解像度変化時に同期ずれやスケーリングの不安定を招くことがあります。Fixed Horizontal Blanks（HBlank）と Fixed Vertical Blanks（VBlank）オプションは映像出力を安定させます。同期に問題がある場合や解像度変化がおかしく見える場合に試してください。

    • Fixed HBlank は PSX 映像出力本来の 4:3 アスペクト比にすべてを収めます。元の解像度が欲しい場合はほぼすべての場面でオンにしてください。
    • Vertical Crop は Fixed VBlank がオンのとき使えます。他のコアの 5x スケーリングに似たもので、多くの PSX ゲームは 224p か 216p を使うため、設定が2つあります。
    • Horizontal Crop は一部の PAL ゲーム向けです。自分に合うものを試してください。

    例：

    • Metal Gear Solid は Fixed HBlank の恩恵を受けます。Fixed VBlank をオンにしないと、一部シーンの画面揺れでモダンディスプレイが同期を失います。
    • Final Fantasy VII は Fixed VBlank の恩恵を受けます。Fixed HBlank だけでは正しい 4:3 アスペクト比になりますが、ワールドマップからバトルに切り替わるとき解像度が目に見えて「ジャンプ」します。Fixed VBlank と Vertical Crop -> On (224/270) にすれば、この遷移でも違和感のある解像度・画面位置の変化は起きません：

    このようなゲームは他にもあります。何が最適か試してみてください。

    Black Transitions

    解像度や画面の遷移が速すぎて、DDR3 のフレームバッファーが完全にクリアされないことがあります。このオプションは、スケーリング映像（HDMI または vga_scaler）上に前のフレームの残像が出るのを防ぎます。

    デインターレース方式

    MiSTer PSX コアは、PlayStation で時折出るインターレース映像のデインターレースを2方式で対応しています。デフォルトの Weave は多くの場面で好まれ、最も安定した画像が得られます。Bob はかなり揺れますが、実機 CRT では状況によって良く見えることがあります。

    Sync 480i for HDMI

    このオプションは HDMI ディスプレイで遊ぶとき 480i 出力を同期させます。多くのディスプレイで 480i から 240p への解像度変化の速度が改善されます。

    Rotate

    画面を180°回転させる必要がある場合、OSD の Audio and Video オプションで "Rotate" をオン／オフします。

    ディザリング オン/オフ

    ディザリングはオン／オフできます。ゲームによっては望ましくないカラーバンディングを起こしますが、他では市松模様をほぼロスなく消せます。ゲームごとに最適な設定を見つけてください。

    Render 24-bit

    24ビットレンダリングを有効にします。ディザリングなしでカラーバンディングを避けつつ、一部ゲームのグラフィックがかなり滑らかになることがあります。試してみてください。

    Dither 24-bit for VGA

    MiSTer の Analog I/O ボードはもともと 24ビット RGB カラーを想定して設計されていないため、出力されるのは 18ビット映像だけです。このオプションは PSX の 24ビット映像ソース（ほとんどの場面は 24ビットではなく、通常は一部ゲームの FMV シーケンスのみ）をディザリングして、アナログ映像で欠けた6ビットが目立たないようにします。HDMI 映像には効果がなく、フル 24ビット RGB 対応の Direct Video アダプターを使っている場合は使うべきではありません。

    ワイドスクリーンハック

    MiSTer PSX コアにはワイドスクリーンハックモードがあります。多くのゲームはほぼ全面 3D で 2D 要素が少ないため、3D モデルを引き伸ばさずに見える風景を横に広げられる可能性があります。うまくいくゲームとそうでないゲームがあり、結果はまちまちです。3:2、5:3、16:9（モダンディスプレイの多くがこれ）の複数アスペクト比があり、さまざまなディスプレイとゲームに選択肢を残しています。R4 - Ridge Racer Type 4 の例：

    テクスチャフィルター

    PlayStation には他のコンソール（代表例は Nintendo 64）のような内蔵テクスチャフィルタリングがありませんでした。そのため多くのテクスチャはエッジが粗いものでした。場合によってはそれで良いのですが、非常に目障りなゲームもあります。MiSTer PSX コアのこのオプションで 3D オブジェクトのテクスチャを滑らかにできます。良い例が Tony Hawk's Pro Skater 2 で、下の動画をご覧ください：

    SPU RAM select

    MiSTer PSX コアは、オプションのデュアル SDRAM モジュールに対応した最初のリリースコアです。開発初期に必要でした。単一 SDRAM モジュールでは、SDRAM に同時に置く必要のある他のコンポーネントと一緒にテスト ROM や小さなゲームを収める帯域が足りなかったためです。PSX コアでデュアル SDRAM が必要だったのはずっと昔の話で、正式リリースは Analog I/O ボード互換のシングル SDRAM ビルドです。

    ゲーム実行中にこのオプションを切り替えると、ほぼ確実にゲームがクラッシュします。デュアル SDRAM ビルドのコアでこのオプションを有効にした場合、動かすにはゲームをリセットする必要があるでしょう。

    MiSTer PSX コアのデュアル SDRAM ビルドで知られる唯一の違いは知覚できません。音声サンプルが1ミリ秒のごくわずかな分だけ正確になるだけで、44,100 サンプル毎秒のうち1〜2個が欠けても人間の耳には分かりません。

    SPU にデュアル SDRAM を使うこのオプションは、コアの通常リリースではデフォルトで無効です。デュアル SDRAM 対応ビルドを得るには、"PSX_DualSDRAM.qpf" Quartus プロジェクトファイルを Quartus 17.0.2 で自分でコンパイルするか、MiSTer FPGA Discord の #test-builds チャンネルで最新テストビルドを入手してください。

    その他のオプション

    この節では、互換性と引き換えに PlayStation ゲームのパフォーマンスを上げられるスピードハックと、情報オーバーレイを説明します。

    Fastboot

    ファストブートはゲーム起動時の BIOS ブートロゴと画面をバイパスします。ゲームに入るのがかなり速くなりますが、ごく少数のゲームでバグや互換性の問題が出ることがあります。ゲームでバグに気づいたら、バグレポートを出す前にまず Fastboot をオフにしてください。

    Unsafe Options

    コアには一部のゲームでプレイを改善するさまざまなオプションがありますが、すべてのゲームで安定しているとは言えません。これらを1つ以上使っている場合、コアはゲームを起動するたびに警告を表示します。

    注意：これらのオプションをオンにした状態でバグ報告をしないでください。まずオプションなしで問題が続くか確認してください。

    • 480i to 480p hack: 一部のゲームをフル 480p 解像度でレンダリングし、480i 3D ゲームの揺れを減らしてインターレースの横線を消します。フル 3D の 480i タイトルの一部でのみ動作し、ゲームによってはバグっぽく見えることがあります。
    • Turbo: CPU、DMA、メモリー、GTE の性能を 約10%（Low）、約20%（Medium）、50%（High）向上させます。Turbo オンの間はチートが使えず、自動で無効になります。
    • Pause when CD slow: CD データは決められた時間内に返る必要があり、そうでない場合コアはデータが届くまでポーズします。無効にするとこのポーズはなくなりますが、CD データの到着が遅れたときにゲームがハングする危険があります。
    • PAL 60Hz Hack: PAL ゲームを 60 Hz で動かします。このハックで PAL ゲームはしばしば速く動きます。このモードでは画面の高さが 256 ラインに制限されるため、一部のゲームは上下が切れることがあります。
    • CD Fast Seek: CD が最小限の時間で次のセクターへシークします。ロード時間が短くなりますが、長いロード時間に依存するゲームはクラッシュします。
    • CD Speed: CD ドライブを固定の高速で回してロード時間を短くしますが、長いロード時間に依存するゲームはクラッシュします。FMV や CD 音声再生時は自動で本来の速度に落ち、ロード区間で再び加速します。高速設定ほど不安定で適切なストレージが必要です。この点では BIN/CUE ファイルが CHD より性能が良いです。
    • Limit Max CD Speed: ゲームが前のデータを処理するまで新しい CD データを抑えます。高速モード使用時の CD データオーバーランを防ぐのに主に有効で、読み取りリトライの減少により全体的なロード時間が速くなります。
    • RAM: 開発機にあった 8 MB オプション。必要とするホームブリューにのみ使ってください。それ以外ではゲームがクラッシュする可能性が高いです。
    • GPU Slowdown: GPU フィルレートを下げます。

    オーバーレイ

    3つの情報オーバーレイがあり、デフォルトで無効です：

    • FPS Overlay - フレームレート（毎秒フレーム数）。
    • Error Overlay - エラーメッセージ（後述のエラーメッセージ参照）。
    • CD Slow Overlay - CD アクセス時間が想定より遅いときにインジケーターを表示。ROM ストレージに回転式ハードディスクや NAS を使っている場合、予期しない遅延があるとコアはポーズしてデータを待ちます。このインジケーターはその発生を示します。

    MiSTer PSX コアでチートを使う

    PSX のチートは他の MiSTer コアとは違う方法で検出されます。他のコアでは、チートファイルはファイル名に CRC32 ハッシュを持ち、読み込んだ ROM の CRC32 と照合されます。PSX（およびチート対応の他の CD ベースコア）では異なります。CD イメージは CRC32 チェックには大きすぎるため、代わりに内部の Game ID をスキャンし、同じ Game ID のチートファイルを読み込みます。たとえば Final Fantasy VII Disc 1 を読み込むと、MiSTer は Game ID SCUS-94163 を検出し、./cheats/PSX/ から SCUS-94163.zip を読み込みます。OSD で Data Cache 拡張を有効にするとチートは無効になり機能しません。これは仕様です。

    コアのバリアント

    このコアには PSX2XCPU と呼ばれる内部バリアントがあります（PSX turbo コア、または 2X と略されることも）。

    公式には配布されておらず、手動インストールが必要です。ここではあくまで参考として文書化しています。

    このバリアントは CPU を約 33 MHz から 66 MHz へ2倍に高速化します。他の非公式／実験的なデュアル SDRAM バリアントと違い、128 MB SDRAM ボード1枚だけを使います。公式版と比べて恩恵のあるゲームはごく少数で、一般的には公式コアの Turbo オプションで十分です。

    2X バリアントで Turbo をオンにすると、CPU は元の最大3〜4倍速で動く可能性があり、速すぎることがあります。たとえばゲームがハングする危険はかなり高くなります。

    このバリアントは現在コアリポジトリーのブランチとして存在します。

    これらの実験的ビルドで問題報告をしないでください。

    エラーメッセージ

    MiSTer PSX コアが問題を認識すると、どのエラーが起きたかを示すエラーオーバーレイが表示されます。デフォルトでオンになっている "Error Overlay" OSD オプションでメッセージを隠せます。

    エラーコード一覧：

    • E2 - CPU 例外（ゲームに問題が見える場合のみ関係）
    • E3 〜 E6 - GPU ハング（例：壊れたディスプレイリスト）
    • E7 - mask-AND 有効時の CPU2VRAM
    • E8 - DMA chopping 有効
    • E9 - GPU FIFO オーバーフロー
    • EA - SPU タイムアウト
    • EB - DMA と CPU のインターロックエラー
    • EC - DMA FIFO オーバーフロー
    • ED - CPU Data/Bus リクエストタイムアウト — BIOS が見つからない／壊れている、または SDRAM モジュール未装着でも出る
    • EE - タイマーレポートとしての Dotclock（ゲームに問題が見える場合のみ関係）
    • EF - SPU の BusWidth が 8ビットに設定された（本来は 16ビット）
