一部の MiSTer コアはゲーム内でチートを適用できます。チートは特定のフォーマットを使い、ダウンローダースクリプト実行時に [gamehacking.org](https://gamehacking.org/){target=_blank} から自動でダウンロードされます。チートファイルには後述のルールがあります。

## セットアップ

チートは `cheats/system/rom_filename.zip` に置きます。`system` はコア名（NES、SNES、Genesis など）です。

例：

`cheats/NES/Taboo (USA).zip` は NES ROM `Taboo (USA).nes` 用

zip ファイル名は ROM 名と正確に一致している必要があります。ROM を読み込むとチートは自動で読み込まれ、対応コアではメニューから有効・無効を切り替えられます。

.zip チートファイルが ROM 名と一致しない場合、チートエンジンは ROM の CRC32 を調べ、CRC32 が一致する .zip チートファイルを選びます。ROM 名マッチは CRC32 チェックより優先されます。

個々のチートは .gg フォーマットで、zip ファイル内に格納します。

## CD-ROM イメージでチートを使う

CD-ROM イメージは大きいため、MiSTer は意図的に CRC32 ハッシュをチェックしません。CD イメージでチートを使うには、チート zip を CUE/BIN または CHD ファイルと同じフォルダーに置きます。チートは通常、ファイル名で CD イメージと照合されます。チート zip のファイル名は CUE、CHD、ISO のベース名と一致する必要があります。PlayStation コアだけは、ゲーム内部の Game ID（例：SCUS-94163）に基づいてチートを読み込む第2の方法にも対応しています。[MiSTer PSX コアでチートを使う](../highlights/psx.md#using-cheats-on-the-mister-psx-core)を参照。チートが読み込まれない場合は、次を確認してください：

1. チート zip ファイルが目的の CUE/BIN、CHD、ISO と同じサブフォルダーにある。
2. zip ファイル名が CUE、CHD、ISO のベース名と同一（CUE/BIN のペアでは .cue ファイルに合わせる）。
3. **（PSX コアのみ）** 目的のゲームの Game ID が zip ファイルの対象 Game ID と一致する。

他のすべてが正しく見えても CD ゲームのチートが動かない場合、そのゲームのバージョンがチートの作成対象と違う可能性があります。

## 自分でコードを作る

.gg バイナリ形式（16ビット以前のシステムのコードで使用）のチートコードは、4つの情報にデコードできます。アドレス、比較値、置換値、そして比較値を使うかどうかのフラグです。.gg ファイルはこれらを4つの32ビット整数として、リトルエンディアンのバイト順でバイナリに保存します。

たとえばアドレスが `0xFF1CA0`、比較値が `0xB5`、置換値が `0xFF` なら、ファイルはこうなります：

`01 00 00 00  A0 1C FF 00  B5 00 00 00  FF 00 00 00`

最初の4バイトはリトルエンディアン `0x00000001` で「比較あり」を意味し、次の4バイトはリトルエンディアンのアドレス、3番目は比較値、4番目は置換値です。すべてのコードが比較値を使うわけではありません。

複数コードのチートは、同じフォーマットでさらに16バイトをファイル末尾に追加します。
