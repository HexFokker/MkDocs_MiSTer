MiSTer has Real-Time Clock support in many of its cores. If the MiSTer has time set correctly — via network time sync or an RTC board — these cores will show the correct date and time. The core list below is a snapshot and may lag behind current releases; check each core's README.

## Cores with RTC support (and how to test each)

* ao486 (PC) (DATE on MS-DOS prompt)
* Archie (Acorn Archimedes) (Apps > Alarm)
* GBA (checked with Pokémon Sapphire, wall clock in first room)
* Game Boy (GB and GBC) (Pokémon Gold: set clock, go one room right, set day of week, save, restart; clock is in the menu screen)
* MSX ("MSX3") (DATE on MSX-DOS prompt)
* BBCMicro (BBC Micro Master 128K) (PRINT TIME$ in BBC Master mode)
* Menu (on top of the panels)
* Minimig (Amiga) (Utilities > Clock)
* NeoGeo (DIP Settings: ON > BOOK KEEPING > CABINET/COIN, check date of log entries)
* PC8801mk2SR (PC-88) (PRINT DATE$ shows year 85 but the correct month and day; PRINT TIME$ shows the correct time)
* QL (Sinclair QL) (PRINT DATE$)
* SNES (Daikaijuu Monogatari II, Tengai Makyou Zero; after setting the clock, reload the core so that the clock takes the real time)
* TSConf (top of Wild Commander screen, also MaxiClock plugin)
* X68000 (DATE on HUMAN68K prompt)
* Zet98 (PC-98) (DATE on MS-DOS prompt)
* ZXNext (ZX Spectrum Next) (main menu in Next mode)
