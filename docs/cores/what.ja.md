MiSTer の用語でコアとは、特定のシステムや機能を提供する FPGA 設計のことです。ほとんどのコアはコンソール・コンピューター・アーケードシステムを実装しますが、Menu コアはユーザーインターフェイスを提供します。デフォルトでは起動時に MiSTer が Menu コアを読み込みます。`_Console` メニューで `NES` などのコアを選ぶと、FPGA はそのコアの設計で再設定されます。

HDL 開発では「コア」は、大きな FPGA 設計内の再利用可能な IP ブロック（PLL、HDMI、Ethernet、シリアルインターフェースのコアなど）を指すこともあります。これは通常の MiSTer コアの意味とは別の用法です。

## コアを読み込むと何が起きる？

システムコアを読み込むことは、概念的には別のコンソール・コンピューター・アーケードシステムをディスプレイに接続するようなものです。`.rbf` ファイルが、選択したコアとそのコアが必要とする MiSTer フレームワークのロジックで FPGA を設定します。

コアを読み込んでも flash のプログラム/消去サイクルは消費しません。FPGA のコンフィギュレーションは SRAM に保持され、別のコアを読み込むときに置き換わります。

## コアリポジトリーと不具合

MiSTer のコアは、多くの開発者と先行オープンソースプロジェクトの貢献の上に成り立っています。精度・機能網羅・既知の問題はコアによって異なります。インストール要件・対応機能・既知の制限は該当コアの README、リリースノート、issue トラッカーを確認してください。新しい issue を立てる前に既存の issue を検索してください。

MiSTer プロジェクトが管理するリポジトリーは [MiSTer FPGA GitHub organization](https://github.com/MiSTer-devel){target=_blank} を参照。独立して管理されているコアは、インストール手順やサポート窓口が異なる場合があります。それぞれのリポジトリーとドキュメントを確認してください。
