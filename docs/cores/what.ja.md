MiSTer の用語でコアとは、特定のシステムや機能を提供する FPGA 設計のことです。ほとんどのコアはコンソール・コンピューター・アーケードシステムを実装しますが、Menu コアはユーザーインターフェイスを提供します。デフォルトでは電源投入時に Menu コアが読み込まれます。`_Console` メニューで `NES` などのコアを選ぶと、FPGA はそのコアの設計で再設定されます。

ハードウェア記述言語（HDL）の開発者は、FPGA に書き込まれるもの全般を「コア」と呼びます。たとえば MiSTer FPGA フレームワークは Intel の "Altera PLL Core" を使っています。これは開発者がチップのクロック速度を設定できる、再利用可能なロジックブロックです。HDMI コア、Ethernet コア、シリアルデータコアなどがあります。

## コアを読み込むと何が起きる？

システムコアを読み込むことは、概念的には別のコンソール・コンピューター・アーケードシステムをディスプレイに接続するようなものです。`.rbf` ファイルが、選択したコアとそのコアが必要とする MiSTer フレームワークのロジックで FPGA を設定します。

この繰り返しの書き換えが FPGA の寿命を縮めるのでは、と心配になるかもしれません。心配は無用です。コアを読み込み替えても flash のプログラム/消去サイクルで FPGA を消耗させることはありません。コンフィギュレーションは SRAM に保持され、別のコアを読み込むときにそのまま置き換わるだけです。

## コアリポジトリーと不具合

MiSTer のコアは、多くのコントリビューターと先行オープンソースプロジェクトの成果の上に成り立っています。精度・機能網羅・既知の問題はコアによって異なります。MiSTer プロジェクトが管理するリポジトリーは [MiSTer FPGA GitHub organization](https://github.com/MiSTer-devel){target=_blank} を参照。インストール要件・対応機能・既知の制限は該当コアの README、リリースノート、issue トラッカーを確認してください。新しい issue を立てる前に既存の issue を検索してください。

独立して管理されているコアは、インストール手順やサポート窓口が異なる場合があります。それぞれのリポジトリーとドキュメントを確認してください。
