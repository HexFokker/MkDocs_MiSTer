## What is MiSTer FPGA?
**MiSTer** is an open-source project that aims to recreate classic computers, video game consoles, and arcade machines using modern hardware. Cores recreate original-system behavior — accuracy and compatibility vary by core — and you can use peripherals such as mice, keyboards, joysticks, and other game controllers. MiSTer runs on an FPGA board called the [DE10-Nano](http://de10-nano.terasic.com){target=_blank}, which connects to your TV or monitor via HDMI. It can be expanded with various [add-on boards](basics/addons.md){target=_blank} such as a 7-port USB hub, a 128MB SDRAM module, and an I/O Board 9.2 plus AV Board 1.2 (the Analog I/O Board 6.x is the older, legacy option). The project is under active development, with new cores, features, and bug fixes appearing regularly.

## About this fork

This fork revises the upstream documentation for technical accuracy, clarity, and concision. Editorial changes should distinguish core-specific behavior from platform-wide behavior, verify technical claims against current documentation or source code where necessary, and preserve hardware requirements, configuration settings, and exceptions when removing ambiguity or repetition. This is a documentation-only fork; it does not change MiSTer itself.
