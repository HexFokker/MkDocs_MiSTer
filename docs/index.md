### What is MiSTer FPGA?
**MiSTer** is an open-source project that aims to recreate classic computers, video game consoles, and arcade machines using modern hardware. Software and game images run as they would on the original hardware, and you can use peripherals such as mice, keyboards, joysticks, and other game controllers. MiSTer runs on an FPGA board called the [DE10-Nano](http://de10-nano.terasic.com){target=_blank}, which connects to your TV or monitor via HDMI. It can be expanded with various [add-on boards](basics/addons.md){target=_blank} such as a 7-port USB hub, a 128MB SDRAM module, and either a Digital I/O or an Analog I/O board. The project is under active development, with new cores, features, and bug fixes appearing regularly.
