多くの MiSTer コアは、実機のセーブ機能を再現するか、セーブステートでゲームを保存できます。セーブステートに対応していないコアが多いですが、対応コアは着実に増えています。

## 通常のゲームセーブ

MiSTer がゲーム内セーブを microSD カードに書き込むのは、OSD（オンスクリーンディスプレイ）を開いたときだけです。セーブするには：

1. ゲーム内でセーブする。
2. OSD を開いて "Save Backup RAM" を選択。
3. ほとんどのコアでは、もう一度 OSD を開きます。"Saving..." のポップアップが表示されなければ、セーブは書き込まれなかった可能性が高いです。

OSD を開いた状態でセーブを書き込んでいる間、Digital I/O または Analog I/O ボードの黄色い LED が点灯し、完了すると消灯します。

OSD を開く必要があるのは慣れが要りますが、必要な仕組みです。microSD カードは書き込み回数に上限があり、それを超えると故障し始めます。コアは FPGA 上で動くため、いつセーブをファイルに退避するかを伝える*信号*がなければ、ものによってはカードへ毎秒数回という頻度で書き込み続けてしまう可能性があるのです。

## Autosave オプション

microSD カードの書き込み耐久には限りがあるため、デフォルトで Autosave するコアはほとんどありません。Autosave は書き込み頻度が多すぎてカードの寿命を縮めかねないからです。MiSTer の Autosave は OSD を開いたときだけ書き込むので頻繁な書き込みにはならず、提供しているコアではオンにしておくのが推奨です：

1. OSD を開き、Autosave オプションがあればオンにする。
2. コントローラー（またはキーボード）で右を押して2番目の OSD メニューを開き、"Save Settings" を選択。

"Save Settings" はそのコアだけの設定を保存します。他のコアはそれぞれ自分の設定を保持します。

## セーブファイルの変換

ほとんどの MiSTer コアのセーブファイルは、多くの人気エミュレーターと互換性があります。形式が違う場合は、Euan Forrester 氏の [MiSTer Save File Converter](https://savefileconverter.com/#/mister){target=_blank} が変換できます。他の多くのエミュレーターのセーブ形式の変換や、MiSTer のセーブをエミュレーター互換ファイルに逆変換することも可能です。

## セーブのバックアップ

microSD カードからセーブデータを定期的にバックアップしてください。microSD は故障する時、たいてい突然・完全に故障します。[FreeFileSync](https://freefilesync.org/){target=_blank} などのツールが使え、MiSTer の特定フォルダーを対象にしたスケジュールバックアップのバッチジョブを組めます。詳しくは FreeFileSync のドキュメントを参照してください。
