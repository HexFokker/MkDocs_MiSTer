多くの MiSTer コアは、実機のセーブ機能を再現するか、セーブステートでゲームを保存できます。セーブステートに対応していないコアが多いですが、対応コアは着実に増えています。

## 通常のゲームセーブ

多くのコアはゲーム内セーブをエミュレートされたバックアップメモリに保持し、microSD カードに書き込まれるまで保持します。セーブの動作はコアによって異なります。

"Save Backup RAM" オプションのあるコアでは：

1. ゲーム内でセーブする。
2. OSD を開いて "Save Backup RAM" を選択。これで書き込みが開始されます。完了のために OSD を開き直す必要はありません。

microSD カードの書き込み耐久には限りがあります。セーブトリガーまで書き込みを遅らせることで、ゲームがエミュレートされたセーブメモリを更新するたびに書き込むことを避けています。

セーブの書き込み中は、MiSTer の電源を切ったり、リセットしたり、別のゲームを読み込んだりしないでください。

## Autosave オプション

Autosave の動作はコアによって異なります。OSD を開いたときにセーブするコアでは、Autosave が OSD を開いたときに未保存データを自動で書き込むため、"Save Backup RAM" を選ぶ必要がありません。

Autosave を有効にするには（あれば）：

1. OSD を開き、Autosave オプションをオンにする。
2. コントローラー（またはキーボード）で右を押して2番目の OSD メニューを開き、"Save Settings" を選択。

"Save Settings" はそのコアだけの設定を保存します。他のコアはそれぞれ自分の設定を保持します。

## セーブファイルの変換

セーブファイルの形式はコアによって異なります。多くの MiSTer セーブファイルは人気のエミュレーターと互換性があります。形式が違う場合は、Euan Forrester 氏の [MiSTer Save File Converter](https://savefileconverter.com/#/mister){target=_blank} が MiSTer と多くのエミュレーターのセーブ形式を相互変換できます。

## セーブのバックアップ

microSD カードは突然・完全に故障することがあるため、セーブを定期的にバックアップしてください。[FreeFileSync](https://freefilesync.org/){target=_blank} などのツールを使えば、MiSTer の特定フォルダーを対象にしたスケジュールバックアップが組めます。詳しくは FreeFileSync のドキュメントを参照してください。
