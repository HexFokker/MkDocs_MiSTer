多くの MiSTer コアは、実機のセーブ機能を再現するか、セーブステートでゲームを保存できます。セーブステートに対応していないコアが多いですが、対応コアは着実に増えています。

## 通常のゲームセーブ

コアはゲーム内セーブをバックアップメモリに保持し、トリガーがあったときだけ microSD カードに書き込みます。トリガーは、Autosave 有効時に OSD を開くか、手動で "Save Backup RAM" を選ぶかのどちらかです。

Autosave なしの場合：

1. ゲーム内でセーブする。
2. OSD を開いて "Save Backup RAM" を選択。これで書き込みが開始されます。完了のために OSD を開き直す必要はありません。書き込み中または直後に OSD を開くと、"Saving..." メッセージが表示されることがあります。

セーブの書き込み中は、MiSTer の電源を切ったり、リセットしたり、別のゲームを読み込んだりしないでください。多くのコアでは書き込み中に基板の黄色い LED が点灯しますが、同じ LED が他のコア状態にも使われるため、それだけに頼らないでください。

書き込みを遅らせるのには理由があります。microSD カードは書き込み回数に上限があり、それを超えると故障し始めます。いつセーブをファイルに退避するかを伝える*信号*がなければ、コアによってはカードへ毎秒数回という頻度で書き込み続けてしまう可能性があるのです。

## Autosave オプション

デフォルトで Autosave するコアはほとんどありません。MiSTer の Autosave は同じ遅延書き込みの仕組みを使います。OSD を開くと未保存データが自動的に書き込まれるため、頻繁な書き込みにはなりません。提供しているコアではオンにしておくのが推奨です：

1. OSD を開き、Autosave オプションがあればオンにする。
2. コントローラー（またはキーボード）で右を押して2番目の OSD メニューを開き、"Save Settings" を選択。

"Save Settings" はそのコアだけの設定を保存します。他のコアはそれぞれ自分の設定を保持します。

## セーブファイルの変換

ほとんどの MiSTer コアのセーブファイルは、多くの人気エミュレーターと互換性があります。形式が違う場合は、Euan Forrester 氏の [MiSTer Save File Converter](https://savefileconverter.com/#/mister){target=_blank} が変換できます。他の多くのエミュレーターのセーブ形式の変換や、MiSTer のセーブをエミュレーター互換ファイルに逆変換することも可能です。

## セーブのバックアップ

microSD カードからセーブデータを定期的にバックアップしてください。microSD は故障する時、たいてい突然・完全に故障します。[FreeFileSync](https://freefilesync.org/){target=_blank} などのツールが使え、MiSTer の特定フォルダーを対象にしたスケジュールバックアップのバッチジョブを組めます。詳しくは FreeFileSync のドキュメントを参照してください。
