MiSTer はキーボードのキー割り当て変更（リマップ）に対応しています。小型キーボードや各国配列のキーボードに便利です。リマップはシステム全体に適用され、すべてのコアで同じキー配置が使われます。マクロキー機能はありません。単一キーを別の単一キーに割り当て直すだけです。一部のマルチメディアキーは複数の[キーコード](https://www.scs.stanford.edu/10wi-cs140/pintos/specs/kbd/scancodes-5.html){target=_blank}を発行するためリマップできません。キーボード機種ごとのキーマップは `/media/fat/config/kbd_[VID]_[PID].map` に保存されます。すべてのキーをデフォルトに戻すには、ファイル名の VendorID と ProductID が一致する map ファイルを削除してください。キーリマップは Menu コアからのみ行えます。

## ジョイスティックエミュレーション

キーボードはジョイスティックエミュレーションに切り替えられます。ジョイスティック用キーは、ジョイスティックと同じ方法で定義してください。連射もジョイスティックと同様に（Menu+ボタンで）使えます。「KBD TOGGLE」に割り当てたボタンで、定義済みキーのキーボード用途とジョイスティック用途を素早く切り替えられます。

## マウスエミュレーション

キーボードはマウスエミュレーションに切り替えられます。マウスエミュレーション用ボタンは Menu コアの Define Gamepad メニューで、ジョイスティックと同じ方法で定義してください。

## エミュレーション切り替え

エミュレーションモードを切り替えるには、++num-lock++ または ++scroll-lock++ を目的のモードになるまで押してください。

切り替え順は `Mouse >> Joy1 >> Joy2 >> None` です。

キーボードの LED がモードを示します：

* マウスエミュレーション：NumLock LED + ScrLock LED
* ジョイスティック1エミュレーション：NumLock LED
* ジョイスティック2エミュレーション：ScrLock LED

## コアでよく使うファンクションキー／同時押し

* ++f12++ - OSD メニュー／サブメニューを開く／閉じる
* ++alt+f12++ - クイックコア選択（Menu コアと同様）
* ++lctrl+lalt+ralt++ - "USER" ボタンと同等。通常エミュレートされたシステムのリセットを実行
* ++lshift+lctrl+lalt+ralt++ - MiSTer リセット（Menu コアを読み込む）

### 補足

* 一部のシステムは書き込みに対応しており、MiSTer のリセット／シャットダウン時に注意が必要です。MiSTer は保留中の書き込みを残さず、できるだけ早くディスクにフラッシュするようになっています。それでも、直前にディスクへ書き込んだ可能性のあるコアをリセットする安全な方法は ++lshift+lctrl+lalt+ralt++ です。再起動前にすべてのキャッシュをディスクに書き出します。書き込み非対応のコアはハードリセットボタンで再起動したり、そのまま電源を切っても問題ありません。
* ++lctrl+lalt+ralt++ の組み合わせは、INI ファイルで他のよく知られた同時押しに変更できます。
