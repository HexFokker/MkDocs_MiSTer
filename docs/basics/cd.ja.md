CD イメージの対応フォーマットはコアによって異なります。CUE/BIN と CHD が一般的ですが、ISO など他の形式を受け付けるコアもあります。対応フォーマットはコアの readme を確認してください。このページでは CD イメージの格納方法と、USB CD ドライブに対応するかどうかを説明します。

## MiSTer が USB CD ドライブに対応する日は来る？ { #will-mister-ever-support-usb-cd-drives }

端的に言えば、USB CD ドライブには対応しておらず、対応の公開計画もありません。

## CUE/BIN フォルダーと CHD ファイル { #cuebin-folders-and-chd-files }

CUE/BIN は広く対応しています。CUE/BIN のゲームはそれぞれ専用のフォルダーに入れ、他の CUE/BIN ゲームと分けてください。

多くの CD ベースコアは CHD にも対応しています。CHD ファイルは一般に専用フォルダーを必要としませんが、コア固有のフォルダー要件には従ってください。たとえば PSX はセーブファイルを作成する際にゲームのフォルダー名を使います。

## マルチディスクのゲーム { #multi-disc-games }

一部の CD ベースコアはマルチディスクゲームに対応していますが、フォルダー構成、セーブの扱い、ディスク交換の手順はコアによって異なります。

**PSX：** 各ゲームを専用フォルダーに入れ、マルチディスクゲームの全ディスクをそのフォルダーにまとめます。コアはセーブファイルをサブフォルダー名で命名するため、全ディスクで1つのセーブファイルを共有します。コアをリセットせずに、同じゲームの別ディスクイメージを読み込んでディスク交換できます：

```
./Valkyrie Profile (USA)/Valkyrie Profile (USA) (Disc 1).chd
./Valkyrie Profile (USA)/Valkyrie Profile (USA) (Disc 2).chd
```

**3DO：** ゲームがディスク交換を促したら、NVRAM にセーブしてから次のディスクを読み込みます。

その他のコアについては、対応イメージ形式とマルチディスク手順をコアの readme で確認してください。
