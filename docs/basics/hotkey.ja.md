このページでは MiSTer のホットキーを一覧で紹介します。ホットキーは時間を節約でき、操作によってはキーボードやゲームパッドのホットキーでしかできません。Main Menu コアでしか使えないもの、ゲーム中のコア内で使えるもの、どこでも使えるものがあります。

## すべてのコアで、OSD を閉じた状態

| ホットキー                                  | 説明                                                                              |
| ----------------------------------------- | ---------------------------------------------------------------------------------- |
| ++f12++                                   | メニュー／OSD を開く                                                               |
| ++alt+f12++                               | コア選択メニューを開く                                                             |
| ++win+prtsc++                             | スクリーンショットを撮る（アップスケール済み）                                     |
| ++shift+win+prtsc++                       | スクリーンショットを撮る（生出力）                                                 |
| ++lctrl+lalt+ralt++                       | "User" ボタンと同等。通常は現在のコアをリセット。I/O ボードのボタンと同じ           |
| ++lshift+lctrl+lalt+ralt++                | 完全リブート／リセット。I/O 拡張ボードの Reset ボタンと同じ                         |
| コントローラー: ボタンを押しながら Menu ボタンを押す   | そのボタンの連射速度を設定済みレートで順に切り替え、最後にオフ   |
| コントローラー: 方向を押しながら Menu ボタンを押す   | 同上（方向入力用。`autofire_on_directions=1` が必要）             |

## OSD を開いた状態で、すべてのコアで

| ホットキー                     | 説明                                                                  |
| ---------------------------- | --------------------------------------------------------------------- |
| ++f12++                      | OSD を閉じる                                                          |
| ++f11++                      | Bluetooth コントローラーをペアリング                                  |
| I/O ボードの OSD ボタン長押し | Bluetooth コントローラーペアリングの代替方法                          |
| 左                           | 情報画面へ（現在選択中の INI ファイルとボリュームを表示）             |
| 右                           | システム画面（コア変更、フィルター・ガンマ設定など）                  |
| コントローラー: Back + 上下左右 | 定義済みなら代替 INI ファイルを選択（Default/Alt1/Alt2/Alt3）        |
| コントローラー: Select       | 強調表示中の OSD サブメニューを展開                                   |
| コントローラー: ショルダーボタン | コアの OSD オプションを双方向に切り替え                              |

## Main Menu コアでのみ

| ホットキー                          | 説明                                                                   |
| --------------------------------- | ---------------------------------------------------------------------- |
| ++f1++                            | 背景タイプを切り替え（砂嵐、壁紙、カラーバー、黒）                       |
| ++f2++                            | コアの日付表示を隠す／表示                                             |
| ++f9++                            | Linux ターミナル／コマンドラインを開く。F12 でメニューに戻る            |
| コントローラー: **LB** + **X** / **Y** | コントローラーの振動モーターをテスト                                 |

## コア固有のホットキー

### 一部のコンピューターコア

一部のコンピューターコアはキーボードの Windows キー（++win++）を使います。

| ホットキー  | 説明       |
| ----------- | ---------- |
| ++win+f12++ | OSD を開く |

### ライトガン対応コア

一部のコンソールコアは Guncon2、Guncon3、Gun4IR、Sinden などの USB/Bluetooth ライトガンに対応しています。

詳しくは[このガイド](./input.md#using-a-lightgun){target=_blank}を参照。

[キャリブレーションの詳細はこちら。](https://github.com/NolanNicholson/GunCon2-MiSTer?tab=readme-ov-file#calibration-instructions){target=_blank}

| ホットキー         | 説明                                                                       |
| ------------------ | ------------------------------------------------------------------------ |
| OSD 表示中 + ++f10++ | ライトガンのキャリブレーションを開始。白／明るい画面で行うと最も良い結果 |

### セーブステート対応コア

セーブステート対応コアはごく少数です（NES、PSX、GameBoy、GBA、WonderSwan、AtariLynx）。セーブスロットは4つあります。それらのコアでは、標準のセーブステートボタンをコントローラーに割り当てられます（ここでは `SaveStateBtn` と呼びます）：

| ホットキー                                | 説明                                |
| --------------------------------------- | ----------------------------------- |
| ++alt+f1++ - ++f4++                     | スロット1〜4にそれぞれセーブ        | 
| ++f1++ - ++f4++                         | スロット1〜4からそれぞれロード      |
| コントローラー: SaveStateBtn + 左／右    | セーブステートスロットを切り替え    |
| コントローラー: SaveStateBtn + Start + 下 | 選択中のスロットにセーブ            |
| コントローラー: SaveStateBtn + Start + 上 | 選択中のスロットからロード          |
