`#!ini video_mode` INI 設定は、ビデオモードの指定方法をいくつかサポートしています。

## 自動検出
`#!ini video_mode` が未指定の場合、MiSTer はディスプレイ機器の EDID 情報から正しいビデオモードの決定を試みます。これは HDMI ポートに接続された機器に限ります。有効なビデオモードを決定できない場合、安全なプリセットが使われます（720p、または EDID が Full HD 対応を示す場合は 1080p）。

## ビデオモードプリセット（video_mode）
MiSTer には、テレビやモニターの一般的な表示モードをカバーする15個のビデオモードプリセット（0〜14）が内蔵されています。例：
```ini
; Number 8 - 1920x1080 - 60 Hz - 16:9 - FHD 1080p
video_mode=8
```

| 番号   | 解像度     | リフレッシュ (Hz) | アスペクト比 | 名前          |
| ------ | ---------- | ------------ | ------------ | ------------- |
| 0      | 1280x720   | 60           | 16:9         | HD 720p       |
| 1      | 1024x768   | 60           | 4:3          | XGA           |
| 2      | 720x480    | 60           | 3:2          |               |
| 3      | 720x576    | 50           | 5:4          |               |
| 4      | 1280x1024  | 60           | 5:4          | SXGA          |
| 5      | 800x600    | 60           | 4:3          | SVGA          |
| 6      | 640x480    | 60           | 4:3          | VGA           |
| 7      | 1280x720   | 50           | 16:9         | HD 720p PAL   |
| 8      | 1920x1080  | 60           | 16:9         | FHD 1080p     |
| 9      | 1920x1080  | 50           | 16:9         | FHD 1080p PAL |
| 10     | 1366x768   | 60           | 16:9         | WXGA          |
| 11     | 1024x600   | 60           | 128:75       | WSVGA         |
| 12     | 1920x1440  | 60           | 4:3          |               |
| 13     | 2048x1536  | 60           | 4:3          | iPad Retina   |
| 14     | 2560x1440  | 60           | 16:9         | 1440p         |

`video_mode_pal` と `video_mode_ntsc` は同じ値を受け付け、コア出力が約 50 Hz または約 60 Hz の場合に `video_mode` を上書きします。これらの上書きは `vsync_adjust` が 0 以外のときのみ有効です。

## カスタムビデオモード
幅・高さ・リフレッシュレートを指定してカスタムモードを設定できます：
```ini
; 1920x1200 at 75Hz
video_mode=1920,1200,75
```
幅の最大は 4096、高さの最大は 2048、リフレッシュレートは整数または小数（たとえば `59.94`）です。選択したモードを DE10-Nano が出力できない、またはディスプレイが受け付けない可能性があります。推奨される最大映像周波数は 210 MHz で、最大解像度は 2048x1536 に制限されます。[ピクセル反復](#hdmi-pixel-repetition-pr)でさらに解像度を上げられますが、これにも限界があります。

要求したビデオモードのタイミング情報には VESA [Coordinated Video Timings](https://en.wikipedia.org/wiki/Coordinated_Video_Timings){target=_blank} 標準が使われます。デフォルトではこの標準のリデューストブランキング版が使われます。ほとんどのフラットパネルディスプレイと互換性がありますが、古いディスプレイや CRT モニターでは対応が弱いかもしれません。ビデオモードの末尾に `#!ini cvt` フラグを付けると、通常の CVT タイミングが使えます：
```ini
; 1600x1200 on a CRT monitor
video_mode=1600,1200,60,cvt
```
通常の CVT タイミングは同じ解像度でもやや高いクロック速度を必要とするため、高解像度モードの一部は実現できません。[オンラインのビデオタイミング計算ツール](https://tomverbeure.github.io/video_timings_calculator){target=_blank}で2つの方式の違いを理解できます。

## 手動モデルライン
ビデオモードタイミングは、水平タイミング・垂直タイミング・ピクセルクロックを定義する9つの値からなるモデルラインで完全に指定できます：
```ini
video_mode=hact,hfp,hs,hbp,vact,vfp,vs,vbp,fpix
```
さらに2つの値を追加して同期極性を直接指定できます。`hpol`、続いて `vpol` で、それぞれ `0` または `1` です（合計11個の値）。
`hact` と `vact` はそれぞれ水平・垂直の有効（表示）サイズをピクセルで定義します。`hfp`、`hs`、`hbp` は水平フロントポーチ・同期・バックポーチの期間をピクセルで定義します。`vfp`、`vs`、`vbp` は垂直タイミングの同じプロパティです。最後に `fpix` は kHz 単位のピクセルクロック周波数です（ピクセルクロックは通常 MHz で表記されるため、MHz 値に 1000 を掛けてください）。

MiSTer モデルラインは XFree86 モデルラインに似ていますが、情報の表現が少し違います。morf77 氏の[カスタムビデオモードツール](https://github.com/morfeus77/MiSTerTools){target=_blank}（ソース。ホスト版はオフライン）と[モデルライン計算ツール](https://arachnoid.com/modelines/){target=_blank}を組み合わせて、XFree86 モデルラインを MiSTer 用に変換できます。

## 追加フラグ
カスタムモードとモデルラインには追加フラグを付けられます：

 * `#!ini +hsync` / `#!ini -hsync` - 水平同期極性を設定
 * `#!ini +vsync` / `#!ini -vsync` - 垂直同期極性を設定
 * `#!ini pr` - HDMI ピクセル反復を使用（カスタムモードとモデルライン。幅が 2048 を超える場合は自動適用）
 * `#!ini cvt` - 通常 CVT タイミングを使用（カスタムモードのみ）
 * `#!ini cvtrb` - リデューストブランキング CVT タイミングを使用（カスタムモードのみ）

## HDMI ピクセル反復（pr） { #hdmi-pixel-repetition-pr }

HDMI ピクセル反復により、MiSTer は追加リソースや高いクロック速度なしで、より高解像度の映像信号を出力できます。ADV7513 HDMI トランスミッターに、ディスプレイへ送る各ピクセルを複製させることで実現します。最終画像の忠実度は上がりません。多くの場合むしろ下がりますが、選べるビデオモードの幅が広がります。

MiSTer は水平解像度最大 2048 ピクセル、ピクセルクロック最大 210 MHz に制限されています。これで 2048x1536（209 MHz、iPad 解像度）の対応最大ネイティブ解像度と、一部のディスプレイが受け付ける非標準 4:3 解像度 1920x1440（184 MHz）が可能です。より一般的な 2560x1440 モードは届きません。水平解像度とピクセルクロック（240 MHz）の両方で限界を超えます。

ピクセル反復は、水平解像度を 1280 ピクセルに下げてピクセルクロックを 120 MHz にすることで、2560x1440 のようなモードを可能にします。MiSTer スケーラーが生成する 1280x1440 画像は ADV7513 によって横に引き伸ばされ、ディスプレイはフルの 2560x1440 を受け取ります。

![Pixel Repetition Pipeline](img/pixel-repeat.png)

コア出力の不均一なスケーリングに対応するには更新されたフレームワークが必要で、ピクセル反復は更新済みのコアでのみ動作します。古いコアはピクセル反復が必要なモードを要求されると 1920x1080 を出力します。
