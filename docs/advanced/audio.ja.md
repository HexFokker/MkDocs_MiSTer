MiSTer のオーディオフィルターは、音のきつさを和らげバランス良くします。古いゲームシステムの中には、生のデジタル出力を想定していないものがあり、音声ハードウェアとスピーカーの間にアナログオーディオフィルターが入っていました。これらのフィルターは、実際の電子回路で使われる一般的なフィルターを表す数式から生成されています。すべてのフィルターは [Filters_MiSTer GitHub リポジトリー](https://github.com/MiSTer-devel/Filters_MiSTer){target=_blank}にあります。

## フィルターの種類

`Arcade LPF` - 一般的なアーケード筐体のフィルタリングを再現するフィルター。多くのアーケードゲームの生音声は耳にきついため、これらのフィルターで音を柔らげられます。1st と 2nd はフィルターの次数を指します。LPF は「ローパスフィルター」の略で、kHz 値はカットオフ周波数です。

`Core Specific` - 特定コア用のフィルター。例として、あるモデルの Super Nintendo のフィルタリングを再現するものがあります。最新のリストはリポジトリーを確認してください。

`General LPF` - アーケードフィルターよりカットオフ周波数が高い、より汎用的なローパスフィルター（10-20 kHz vs 2-8 kHz）。
