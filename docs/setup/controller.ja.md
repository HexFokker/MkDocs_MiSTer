次に、キーボードとゲームパッドを使って、ゲームパッドの入力を定義します。お持ちのコントローラー種類ごとに1回ずつ行ってください。MiSTer は各機器の固有 ID ごとに設定を保存します。

## ゲームパッドのボタンを割り当てる
Menu コアの OSD の2画面目（Downloader や WiFi スクリプトを実行した画面）を開き、"Define joystick buttons" を選択します：

![Define your gamepad!](img/define-joystick.png)

まず MiSTer は、十字キーやアナログスティックの操作を求めて、コントローラーの大まかな種類を検出します。その後、ボタンの割り当てを求められます：

* 表面ボタン4個とショルダーボタン2個
* Start と Select
* OSD ボタン、または2ボタン同時押し（キーボードの F12 の代わりに使う）
* 高度な機能用の追加ボタン数個

要求されるボタンは次の図のとおりです：

![MiSTer Controller Setup](img/controller-layout.png)

* **ボタンをスキップする：** 割り当てたくないボタン（かなり多い場合があります）は、キーボードの ++space++ か MiSTer の User ボタンでスキップできます。誤ったボタンを割り当てても大丈夫です。最初からやり直せばよいだけです。
* **アナログスティック：** 図の左下の L はアナログスティックです。この設定はリストの一番最後に来るので、スティック付きのコントローラーならリストを最後まで進んでください。早めに ++enter++（"Finish"）を押すとスティックの設定がスキップされ、動作しなくなります。
* **OSD ボタン：** 最近のコントローラーによくある "Home" ボタンがあるなら、OSD/Menu に割り当てるのがおそらく最適です。OSD ボタンも同時押しも割り当てない場合、メニューを開く唯一の方法はキーボードの ++f12++ になります。
