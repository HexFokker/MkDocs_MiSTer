次に、遊びたい機種のコアを読み込みます。この例では NES コアを使います。Console → NES を選び、Enter またはコントローラーで "A" に割り当てたボタンを押します。コアが読み込まれたら、割り当てた Menu ボタン（またはキーボードの F12）をもう一度押してメニューを開き直す必要がある場合があります。そして Load ROM を選んでゲームを読み込みます。

セーブ機能のあるゲームなら、Autosave をオンにしてください。MiSTer は、いつカードにセーブを書き込むかを教えてもらう必要があります。Autosave がない場合、ゲーム内でセーブするたびに（たとえば NES のファイナルファンタジー）、OSD を開いて "Save Backup RAM" を選ばなければなりません。Autosave をオンにしておけば、メニューを開くだけで書き込まれるので、忘れずに済みます。詳しくは[セーブデータ](../basics/saves.md)を参照。

コアのメニューで変更した設定は、保存しないと失われます。Autosave を維持するには、コアの2番目の OSD メニューに切り替えて（コントローラーで右を押す）"Save Settings" を選択してください。
